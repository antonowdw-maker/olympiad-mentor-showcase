# Как проверяется контент: многомодельный аудит

Служебные документы для агентов и ревьюеров. Обзор проекта — [`../../README.md`](../../README.md).

Эталонный ответ задачи нельзя принимать на веру, даже если его написала сильная модель. Поэтому пакет задач проходит несколько независимых слоёв проверки, и закрывает его только последний:

1. **Implementer** правит сиды, пишет решатели и proofs (пересчёт ответов кодом), проходит самопроверку по ролям.
2. **V1-text** — другая модель, без доступа к файлам: арифметика, согласованность, формулировки по тексту отчёта.
3. **V2-files** — ещё одна модель, только чтение, с доступом к проекту: сиды против источников, решатели, рисунки, трекер, БД.
4. **Владелец** принимает решения и даёт команду на коммит, пуш и мерж.

| [`PROMPT-VERIFIER.md`](PROMPT-VERIFIER.md) | Промпт слоя V1-text |
| [`PROMPT-VERIFIER-2.md`](PROMPT-VERIFIER-2.md) | Промпт слоя V2-files |

Документ витрины. Полный банк, трекер `content/sources/`, решатели `lib/content/audit/`, отчёты и локальные материалы (`docs/audit/`, `docs/doc/`, `tmp-*`, `docs/REVIEW*`) находятся в приватном репозитории; упоминания этих путей описывают его. Отчёты, журнал пакетов и правила агента для пакета не публикуются.

## Глоссарий

| Термин | Значение |
|--------|----------|
| **Канон** | Исходная задача банка |
| **Вариант / изоморф / instance** | Задача с той же идеей и другими данными; у каждого канона их три, считая сам канон (в сиде: канон, `i1`, `i2`) |
| **Эталон** | Правильный ответ, по которому сервер проверяет решение |
| **Official** | Ответ из открытого источника (листок или файл организаторов); для файла — путь и sha256 |
| **Proofs** | Отчёт с пересчётом ответов решателями и выкладками |
| **Страта риска** | Задачи с усиленной проверкой, например без файла официального решения |
| **Класс A** | Неверный эталон |
| **B1 / B2 / B3** | Правка: уточнена формулировка (B1 — по употреблению в отчётах, в playbook определения нет) / изменены числа / вырожденный вариант заменён (например, ответ был прямо в условии) |
| **Класс B** | Условие дословно, вопрос переформулирован под формат ответа |
| **Класс H** | Подсказка выдавала ответ |
| **Класс V** | Канон возвращён к дословному тексту той же позиции источника с тем же ответом; прогресс сохраняется |
| **Класс R** | Канон заменён новой задачей из первоисточника; прогресс по ней сбрасывается |
